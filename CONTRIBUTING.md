# Contributing

Thanks for helping improve Local Video Compressor. This is an experimental, largely AI-assisted project; review and test changes carefully rather than assuming generated code is correct.

- Open an issue for bugs or feature proposals. Include Windows version, installation route (classic or MSIX beta), steps to reproduce, expected and actual behavior.
- Do not upload private videos, unredacted file paths, logs containing personal data, or credentials.
- Pull requests are welcome. Keep them focused, explain the change, and describe how you tested it. For installer, signing, registry, or shell-extension changes, call out any security or rollback implications.
- Do not commit signing keys, certificates with private keys, binaries built from unverified sources, or local settings/logs.

The maintainer may ask for changes or decline a proposal. There is no guaranteed response time or support commitment.
