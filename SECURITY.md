# Security

This experimental, AI-assisted project has not undergone an independent security audit. Use it at your own risk, especially the self-signed MSIX beta installer, which changes Windows certificate trust settings.

Please report security vulnerabilities privately through GitHub's **Report a vulnerability** feature for this repository. Do not post exploit details, credentials, private videos, or sensitive logs in public issues.

There is no guaranteed response time or support commitment. For ordinary bugs and improvements, use GitHub Issues or a pull request.
